# 🌍 Wanderlast - Discover Your Next Adventure

A modern, fully responsive travel booking landing page built with **HTML5** and **CSS3**. This project showcases a beautiful UI with a hero section, featured destinations, testimonials, and a call-to-action section.

## ✨ Features

- 🎨 **Modern & Clean Design** — Minimalist layout with a teal/cyan color scheme.
- 📱 **Fully Responsive** — Works seamlessly on desktop, tablet, and mobile devices.
- 🖼️ **Hero Banner** — Eye-catching banner with a background image and search bar.
- 🔍 **Search Bar** — Functional search bar with location, date, and people filters.
- 🏝️ **Featured Destinations** — Showcases popular travel destinations with cards.
- ✅ **Why Choose Us** — Highlights key features (Safe & Secure, Expert Guides, 24/7 Support).
- 💬 **Testimonials** — Real experiences from happy travelers.
- 📢 **CTA Section** — Strong call-to-action to encourage bookings.
- 📧 **Newsletter** — Email subscription form in the footer.
- 🎯 **Font Awesome Icons** — Scalable vector icons for buttons and social links.
- ✍️ **Google Fonts** — "Poppins" font for a professional typography.

## 🎯 Sections Overview

### 1. **Navbar**
- Logo (Wanderlast)
- Navigation menu (Home, Destinations, My Bookings, Admin)
- User actions (Profile, Login, Sign Up)

### 2. **Hero Section**
- Eye-catching headline: "Discover Your Next Adventure"
- Subtitle with description
- Search bar (Location, Date, People)
- Explore Now / View Destination buttons

### 3. **Featured Destinations**
- Section heading with "All Destinations" button
- 3 destination cards with images, ratings, prices, and duration
- "Book Now" links
- Pagination (1/5) with arrow buttons

### 4. **Why Choose Wanderlast**
- Section heading with 3 feature cards:
  - Safe & Secure
  - Expert Guides
  - 24/7 Support

### 5. **What Travelers Say**
- Section heading with navigation arrows
- 2 testimonial cards with quote, name, location, and image

### 6. **CTA Section**
- Background image with dark overlay
- Headline: "Ready To Start Your Journey?"
- Subtitle with description
- "Book Your Trip Today" button

### 7. **Footer**
- Logo + tagline
- Newsletter subscription form
- Quick Links (Home, Destinations, My Bookings, My Profile)
- Support (Help Center, Terms of Service, Privacy Policy)
- Contact Us (Phone, Email)

🎨 Customization Guide
Change Primary Color
Edit styles/style.css:

css
:root {
    --primary-color: #00A8CC; /* Change this to your preferred color */
}
Change Fonts
Edit the Google Fonts link in index.html:

html
<link href="https://fonts.googleapis.com/css2?family=Your+Font&display=swap" rel="stylesheet">
Update Content
Simply edit the text inside index.html to replace placeholder content with your own.
