# 🌟 Mary Hardy Portfolio Website

A modern, responsive personal portfolio website built with **HTML5** and **CSS3**. This project showcases a clean design with a hero banner, about section, skills, resume (education & experience), and a contact form with social media links.

## ✨ Features

- 🎨 **Modern & Clean Design** — Minimalist layout with a primary orange color scheme.
- 📱 **Fully Responsive** — Works seamlessly on desktop, tablet, and mobile devices.
- 🖼️ **Hero Banner** — Eye-catching banner with a professional profile image.
- 👤 **About Me Section** — Personal information displayed in clean info cards.
- 💼 **Skills Section** — Showcases technical skills (JavaScript, React, Node.js, MongoDB).
- 📄 **Resume Section** — Separate columns for Education and Experience.
- 📬 **Contact Form** — Functional contact form with social media links.
- 🎯 **Font Awesome Icons** — Scalable vector icons for buttons and social links.
- ✍️ **Google Fonts** — "Open Sans" font for a professional typography.

## 🎯 Sections Overview

### 1. **Header / Navbar**
- Logo with custom color accent
- Navigation menu (Portfolio, Blog)
- "Hire Me" call-to-action button

### 2. **Hero Banner**
- Introduction with name and title
- "Download CV" and "Contact" buttons
- Professional profile image

### 3. **About Me**
- Short bio paragraph
- Personal information cards (Name, Email, Date of Birth, Location)

### 4. **Skills**
- Four skill cards: Vanilla JavaScript, React, Node.js, MongoDB
- Icons and descriptions for each skill

### 5. **Resume**
- Two-column layout: Education & Experience
- Timeline-style resume cards
- "Download CV" button

### 6. **Footer / Contact**
- Social media links (Facebook, Twitter, Instagram)
- Contact form with name, email, and message fields
- Submit button
